# Audio-Reader

Приветствую! Это программа для записи звука с аудиовыхода при помощи Windows API. Если сказать чуть подробнее, то эта программа записывает весь звук, который вы слышите в наушниках или колонках, с записью в .wav файл (в будущем планирую добавить возможность выбора формата, в который вы хотите сохранить файл).

Правда, не весь звук она способна записывать. Проблема в том, что существует защищенный просмотр, который не дает записывать ничего, по крайней мере через Windows API. Поэтому, если захотите записать, например, звук из сериала по платной подписке от Netflix, скорее всего, не получится, но в любом случае попытайтесь.
